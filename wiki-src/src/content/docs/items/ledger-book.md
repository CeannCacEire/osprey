# Overview

The Ledger Book is what's left when a Ledger Chest is broken: a written book holding that chest's latest 100 transactions, showing who put in or took out what, and when. It's evidence you can carry, store, trade or show to someone. It cannot be destroyed.

## Getting one

The only way to get a Ledger Book is to break a Ledger Chest. Whoever breaks it gets the Book, whether they own the chest or not. It can't be crafted. Here's the format so you know it's legit:


• **Title**: "Ledger of [name]" if the chest was named in an anvil, otherwise "Ledger Book".

• **Author**: Ledger.

The chest's own log is deleted when it breaks, so the Book is the only record left of what happened in it.

## Record

Open it like any written book. It works the same on Java and Bedrock.

It holds the chest's newest 100 entries, set out oldest first with a few to a page. Each line gives the time, who, what they did, how many and the item:

`Oct 28 23:35  MRDOGO5779 took 12 Iron Ingot`

`Oct 28 23:41  Steve put in 5 Oak Log`

`Oct 29 02:00  A hopper took 64 Cobblestone`

| Who the line names | What it means |
| :--- | :--- |
| A player | That player put in or took out the items. |
| Two players, such as "MRDOGO5779 or Steve" | Both had the chest open at the same moment, so it couldn't tell whose hand moved the items. |
| A hopper | A hopper, dropper or hopper minecart moved the items. These are added up per item for each hour, so a busy hopper line takes only a few lines. |

Only items going in or out are recorded. Opening the chest and looking leaves no line. If nothing was ever recorded, the Book says "Nothing was recorded."

## Evidence

A Ledger Book can be stored anywhere, like any other item. It's also protected so the evidence can't be destroyed or forged:

• **It can't be destroyed**. Lava, fire, cactus, explosions and lightning don't harm it when it's on the ground.

• **It never despawns**. A dropped Book stays put, and it glows so it's easy to find.

• **It comes back from the void**. If it falls out of the world, it reappears at that world's spawn.

• **Mobs can't pick it up**. Give up on hiding it on a Zombie!

• **It can't be copied**. Putting it in a crafting grid with a book and quill makes no copy.

• **It can't be edited**. It's a signed book so the entries stay as they were written.
