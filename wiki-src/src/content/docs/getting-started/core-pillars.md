## I. Finite Resources

Osprey is based on a beautiful, custom 5000 × 5000 island surrounded by nothing but ocean. All biomes and structures are contained within.![](/wiki/images/uploads/pasted-image-1793647920060.png)

## II. Player Choice

Power is in your hands. Want to monopolize a resource? Wage war? Banish bad actors? Become rich? Live alone? Live in kingdoms? Live peacefully? Live violently? On Osprey, you decide how to play.

Be warned, though: it's better to make friends than enemies.![](/wiki/images/uploads/20261102-113323.png)

## III. No Learning Curve

[Falcon](/wiki/getting-started/falcon/) is our server core and automates many features that, on many other servers, would require several commands to use. On Osprey, everything is built natively upon vanilla gameplay. This also ensures native Bedrock compatibility.
![](/wiki/images/uploads/20261102-113931.png)
