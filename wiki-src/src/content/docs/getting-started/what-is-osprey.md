Osprey is a cross-compatible Vanilla+ server built upon the revolutionary [Falcon](/wiki/getting-started/falcon/) infrastructure.

Osprey is a Vanilla+ civilisation server based upon a 5000 × 5000 island that aims to solve the issues plaguing many other servers. As a player-led server, griefing, looting, aggressive admin oversight and excessive commands are all addressed. No claims, no wands, no rollbacks, no scripts, no commands. And yet, thanks to Falcon, our proprietary backend software, you can build, trade, fight and dominate without a second thought. All systems are built directly upon vanilla, making Osprey fully cross-compatible with Bedrock clients without any compromise.

Gather your friends, build a kingdom, and reign supreme on Osprey. Resources won't last forever.
